# ghostjs8 (bridge package)

Python package for ghost.js8: KiwiSDR receiver adapter, JS8Call decoder
adapter + in-container decoder-agent, session orchestration, the browser
WebSocket API, and test simulators (`ghostjs8.sim`). See the repository
`README.md` and `AGENTS.md`.

Commands: `python -m ghostjs8 {bridge|agent|fake-kiwi|acceptance}`.
